# Project A

Веб-приложение для управления задачами.

## Технологии

- Python
- Flask
- pytest
- Project B

## Установка

Создать виртуальное окружение:

python -m venv .venv

Активировать:

.\.venv\bin\Activate.ps1

Установить зависимости:

pip install -r requirements.txt

## Запуск

python src/main.py

## Тестирование

pytest
